# Audio Noise Reduction Using FIR Window Techniques

## Project Overview
This project focuses on reducing unwanted noise from audio signals using Finite Impulse Response (FIR) filters designed with window techniques.

## Objectives
- Understand FIR filter design.
- Implement window-based filtering techniques.
- Reduce unwanted noise in audio signals.
- Compare audio signals before and after filtering.

## Window Techniques
The project explores the following window functions:
- Rectangular Window
- Hamming Window
- Hann (Hanning) Window
